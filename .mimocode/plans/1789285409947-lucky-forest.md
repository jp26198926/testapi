## Part 2: Forgot password feature

Better Auth v1.7.3 has built-in support for forgot/reset password. The flow:
1. User clicks "Forgot password?" on login page → `/forgot-password`
2. User enters email → calls `authClient.requestPasswordReset({ email, redirectTo })` → sends reset link via email
3. User clicks link in email → redirected to `/reset-password?token=...`
4. User enters new password → calls `authClient.resetPassword({ newPassword, token })` → password updated

### 2a. Install nodemailer
```bash
npm install nodemailer
npm install -D @types/nodemailer
```

### 2b. Create `lib/email.ts` — SMTP email utility
- Uses `nodemailer.createTransport()` with SMTP env vars (SMTP_HOST, SMTP_PORT, SMTP_USER, SMTP_PASS, SMTP_SECURE)
- Exports `sendEmail({ to, subject, html })` function
- Uses SMTP_FROM / SMTP_FROM_NAME for sender

### 2c. Edit `lib/auth.ts` — add sendResetPassword callback
```ts
emailAndPassword: {
  enabled: true,
  sendResetPassword: async ({ user, url, token }, request) => {
    // send email with reset link using lib/email.ts
  },
  revokeSessionsOnPasswordReset: true,
},
```

### 2d. Edit `lib/auth-client.ts` — export forgot/reset methods
Add `forgotPassword` and `resetPassword` to the destructured exports from `authClient`.

### 2e. Create `app/(auth)/forgot-password/page.tsx`
- Client Component
- Form with email field
- Calls `authClient.requestPasswordReset({ email, redirectTo: "/reset-password" })`
- Shows success message: "If an account exists with that email, we sent a reset link."

### 2f. Create `app/(auth)/reset-password/page.tsx`
- Client Component
- Reads `token` from URL search params
- Form with new password + confirm password fields
- Calls `authClient.resetPassword({ newPassword, token })`
- On success, redirects to `/login` with success message
- On error (invalid/expired token), shows error

### 2g. Edit `app/(auth)/login/page.tsx` — add forgot password link
- Add "Forgot password?" link below the password field, linking to `/forgot-password`
