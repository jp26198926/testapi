## 1. Create `payments` table + Drizzle schema

**File:** `lib/db/schema.ts`

Add a `payments` table to log PayPal payment events:

```ts
export const payments = pgTable(
  "payments",
  {
    id: uuid("id").primaryKey().defaultRandom(),
    userId: text("user_id").notNull().references(() => users.id, { onDelete: "cascade" }),
    subscriptionId: uuid("subscription_id").references(() => subscriptions.id, { onDelete: "set null" }),
    providerPaymentId: text("provider_payment_id"),
    amount: text("amount").notNull(),
    currency: text("currency").notNull().default("USD"),
    status: text("status").notNull(), // completed, denied, refunded, pending
    description: text("description"),
    createdAt: timestamp("created_at").notNull().defaultNow(),
  },
  (table) => [
    index("payments_user_id_idx").on(table.userId),
    index("payments_subscription_id_idx").on(table.subscriptionId),
  ]
);

export const paymentsRelations = relations(payments, ({ one }) => ({
  user: one(users, { fields: [payments.userId], references: [users.id] }),
  subscription: one(subscriptions, { fields: [payments.subscriptionId], references: [subscriptions.id] }),
}));
```

Also add `payments: many(payments)` to `usersRelations`.

**Then:** Generate migration (`npm run db:generate`) and run it (`npm run db:migrate`).

## 2. Log payments in PayPal webhook handler

**File:** `app/api/webhooks/paypal/route.ts`

Insert into `payments` table on these events:
- `PAYMENT.SALE.COMPLETED` → status `"completed"`, amount from `resource.amount.total`
- `PAYMENT.SALE.DENIED` → status `"denied"`
- `PAYMENT.SALE.REFUNDED` → status `"refunded"`

Look up the `subscriptionId` from the existing subscription record found in the webhook.

## 5. Build reusable `DataTable` component

**File:** `components/data-table.tsx` (new `components/` directory)

A reusable client component matching the project's raw-Tailwind style:

```tsx
type Column<T> = {
  key: keyof T & string;
  label: string;
  render?: (value: T[keyof T], row: T) => React.ReactNode;
};

type DataTableProps<T> = {
  columns: Column<T>[];
  data: T[];
  page: number;
  limit: number;
  total: number;
  totalPages: number;
  onPageChange: (page: number) => void;
  onLimitChange: (limit: number) => void;
  onExportCSV: () => void;
  onExportExcel: () => void;
  loading?: boolean;
};
```

- Renders an HTML `<table>` with Tailwind styling (matching existing zinc-based palette)
- Includes the pagination bar (reusing the existing pattern from collection detail page)
- Includes "Export CSV" and "Export Excel" buttons in the header
- Shows "Showing X-Y of Z records" status
- Loading state with placeholder text

## 6. Build export utility

**File:** `lib/export.ts`

```ts
export function exportToCSV<T>(columns: { key: string; label: string }[], data: T[], filename: string): void
export function exportToExcel<T>(columns: { key: string; label: string }[], data: T[], filename: string): void
```

- `exportToCSV`: Generates CSV string, creates a Blob, triggers download via `URL.createObjectURL`
- `exportToExcel`: Uses `xlsx` library to create a workbook, add a worksheet, and trigger `.xlsx` download
- Both work client-side only (no server roundtrip)
