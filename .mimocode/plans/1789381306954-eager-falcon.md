# Add CORS Support for All API Routes

## Goal

Allow cross-origin requests to all `/api/*` routes with `Access-Control-Allow-Origin: *`.

## Approach

Handle CORS centrally in `proxy.ts` (Next.js 16 middleware). This is the cleanest place because:
- It intercepts all `/api/*` requests before they hit route handlers
- It can respond to `OPTIONS` preflight requests directly
- It can attach CORS headers to every response
- No changes needed to individual route handlers or response helpers

## File: `proxy.ts`

Add a new matcher for `/api/:path*` and handle CORS:

```ts
import { NextRequest, NextResponse } from "next/server";
import { getSessionCookie } from "better-auth/cookies";

const CORS_HEADERS = {
  "Access-Control-Allow-Origin": "*",
  "Access-Control-Allow-Methods": "GET, POST, PUT, PATCH, DELETE, OPTIONS",
  "Access-Control-Allow-Headers": "Content-Type, Authorization, X-API-Key",
  "Access-Control-Max-Age": "86400",
};

export function proxy(request: NextRequest) {
  // CORS for API routes
  if (request.nextUrl.pathname.startsWith("/api/")) {
    // Preflight
    if (request.method === "OPTIONS") {
      return new NextResponse(null, { status: 204, headers: CORS_HEADERS });
    }
    // Attach CORS headers to the response
    const response = NextResponse.next();
    for (const [key, value] of Object.entries(CORS_HEADERS)) {
      response.headers.set(key, value);
    }
    return response;
  }

  // Session guard for dashboard pages
  const sessionCookie = getSessionCookie(request);
  if (!sessionCookie) {
    return NextResponse.redirect(new URL("/login", request.url));
  }
  return NextResponse.next();
}

export const config = {
  matcher: [
    "/api/:path*",
    "/dashboard/:path*",
    "/collections/:path*",
    "/keys/:path*",
    "/playground/:path*",
    "/billing/:path*",
    "/settings/:path*",
  ],
};
```

## Verification

1. `curl -X OPTIONS http://localhost:3000/api/public -H "Origin: http://example.com" -v` — should return 204 with CORS headers
2. `curl http://localhost:3000/api/public -H "Origin: http://example.com" -v` — should include `Access-Control-Allow-Origin: *` in response
3. Browser console: `fetch("http://localhost:3000/api/public")` from a different origin should succeed
