# Admin User Management on Settings Page

## Goal

Add a "Users" card to the admin settings page with: view user list, view details (collections/keys/subscription), change plan (free/pro), delete user.

## Files to Create

| File | Purpose |
|------|---------|
| `app/api/admin/users/route.ts` | GET — paginated user list with plan + collection count |
| `app/api/admin/users/[userId]/route.ts` | GET details + DELETE user |
| `app/api/admin/users/[userId]/plan/route.ts` | PATCH — change plan to free/pro |
| `app/(dashboard)/settings/users-section.tsx` | UI component for the Users card |

## File to Edit

| File | Change |
|------|--------|
| `app/(dashboard)/settings/page.tsx` | Import + render `<UsersSection />` after Plans card |

## API Routes

All routes: `requireAuth()` → `requireAdmin()` (catch → 401/403). Use `apiSuccess`/`apiSuccessWithPagination`/`ERRORS.*`.

### GET /api/admin/users
- Paginated list ordered by `createdAt` desc
- Batch collection counts + active subscriptions for the page
- Return: `id, name, email, createdAt, plan, collectionCount, isAdmin`

### GET /api/admin/users/[userId]
- User row + collections list + API keys (never expose `keyHash`/`encryptedKey`) + subscriptions
- Return effective plan using same rule as `getUserPlan()`

### DELETE /api/admin/users/[userId]
- Block self-delete and admin-email delete
- Drizzle cascade handles all child rows
- Return 204

### PATCH /api/admin/users/[userId]/plan
- Body: `{ plan: "free" | "pro" }`
- Pro: upsert subscription with `provider: "admin"`, `status: "active"`, period from plans table `durationDays` (fallback 30)
- Free: cancel all active subscriptions, set `currentPeriodEnd` to now

## UI Component (`users-section.tsx`)

- `"use client"` component with its own state/fetch
- Card matching existing settings card style
- User rows: name, email, plan badge, collection count, join date, Admin badge
- Actions per row: Make Pro/Make Free (hidden for admin), Details toggle, Delete (hidden for admin, uses `confirm()`)
- Expanded details: collections list, API keys with status badges, subscription info
- Pagination: Prev/Next buttons
- Error/success banners
