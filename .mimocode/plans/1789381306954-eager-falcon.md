# Remove Auth from Private Collection GET Routes

## Goal

GET endpoints for private collections/records become publicly readable (no auth). POST/PATCH/PUT/DELETE retain full auth + ownership checks.

## Changes

### 1. `app/api/collection/[collectionId]/[slug]/route.ts` — GET handler

Remove `requireAuth()` and the `userId` filter from the collection lookup. Just validate ID + slug:

```ts
// GET — no auth required
export async function GET(...) {
  const { collectionId: rawId, slug } = await params;
  const collectionId = parsePositiveInt(rawId);
  if (collectionId === null) return ERRORS.BAD_REQUEST("Invalid collection ID.");

  // ... pagination parsing unchanged ...

  // Look up collection by ID + slug only (no userId check)
  const col = await db
    .select()
    .from(collections)
    .where(eq(collections.id, collectionId))
    .limit(1);

  if (col.length === 0 || col[0].slug !== slug) {
    return ERRORS.NOT_FOUND();
  }

  // ... rest of handler unchanged (fetch records, return) ...
}
```

POST handler: **unchanged** (keeps auth + ownership).

### 2. `app/api/collection/[collectionId]/[slug]/[recordId]/route.ts` — GET handler

Same pattern — remove auth, add a non-ownership record lookup for GET:

```ts
// GET — no auth required
export async function GET(...) {
  const { collectionId: rawColId, slug, recordId: rawRecId } = await params;
  const collectionId = parsePositiveInt(rawColId);
  const recordId = parsePositiveInt(rawRecId);
  if (collectionId === null || recordId === null) {
    return ERRORS.BAD_REQUEST("Invalid ID parameter.");
  }

  // Look up collection by ID + slug only
  const col = await db
    .select()
    .from(collections)
    .where(eq(collections.id, collectionId))
    .limit(1);

  if (col.length === 0 || col[0].slug !== slug) {
    return ERRORS.NOT_FOUND();
  }

  const rec = await db
    .select()
    .from(records)
    .where(and(eq(records.id, recordId), eq(records.collectionId, collectionId)))
    .limit(1);

  if (rec.length === 0) return ERRORS.NOT_FOUND();

  return apiSuccess({ id: rec[0].id, data: rec[0].data, createdAt: rec[0].createdAt, updatedAt: rec[0].updatedAt });
}
```

PATCH/PUT/DELETE: **unchanged** (keep auth + `verifyRecordOwnership`).
